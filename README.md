# RodentX Wildlife Management — Website V2

Distinct, modern, cutting-edge rebuild. No Replit anywhere in this pipeline.

## Concept

**"The X is the system."** Structure mirrors method: Inspect / Remove / Exclude / Monitor.
The X is a seal mark, a crosshair, a closure — not decoration.

- Editorial, oversized typography, huge X moments, sharp grid, generous white space
- Black bands for contrast, single red accent used sparingly (X, active state, one word per headline)
- White / Black / Red / Grey only
- No generic pest-template cards, no stock-photo hero, no gradient blobs

## Structure (single-page, hash-routed)

1. Sticky header — exact Logo A, proportioned, no stretch + nav + "Request Inspection"
2. Hero — "What's in your house?" issue selector routing to the right dossier
3. The X Standard — 01 Inspect / 02 Remove / 03 Exclude / 04 Monitor
4. Species dossiers — Mice & Rats (flagship), Bats in Attic, Raccoons in Attic, Squirrels in Attic, Other Wildlife, Exclusion + Attic Restoration, Commercial
5. Territory — Finger Lakes, Keuka Y in red as home base (Penn Yan), 5 hubs
6. Comeback + FAQ + Contact form (mailto placeholder — no fake endpoint)

## Brand / content rules (do not break)

- **Exact logos only** — `assets/logos.js` holds `LOGO_A`, `LOGO_B`, `LOGO_REV` as base64
  data URIs generated byte-for-byte from the approved `.webp` files. Never redraw as SVG.
- **No pricing anywhere.** No fixed-price quotes.
- **Warranty wording (exact):** "Some exclusion work carries a warranty — coverage for the property is reviewed with you before service begins."
- **No street address.** Service-area only.
- Phone: dummy `(585) 555-0100` · Email: `contact@rodentxwildlife.com` · Canonical: `rodentxwildlife.com` (not yet purchased — do not claim it is live).
- Licensing: "NYS NWCO license renewal in process" — no license number invented.
- Scheduling: "Same-day when available — best to call or submit a form."
- Bats: timing restrictions apply and are explained before work — no dates invented.
- Service area: Finger Lakes Region, NY only. Hubs: Rochester, Syracuse, Ithaca, Canandaigua–Geneva, Penn Yan / Yates County (+ Corning–Elmira edge). Smaller towns live inside hubs, NOT as separate thin pages. No Service × Location matrix.

## Deploy — GitHub is source of truth, Vercel auto-deploys

1. Push this folder to GitHub repo `rodentx-website` (owner `FLOREXHOLDINGS`), branch `main`.
2. In Vercel, import that repo as a static project (no build command, no framework).
   Vercel auto-deploys on every push to `main`.
3. Do NOT reconnect Replit. Do NOT edit in Replit. GitHub + Vercel only.
